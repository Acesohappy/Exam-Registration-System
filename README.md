# 📝 Simple Exam Registration System

## 📌 Overview
The **Simple Exam Registration System** is a lightweight application that allows students to register for exams online. It provides a user-friendly interface for students to enter their details, select subjects, and confirm registration. Admins can view, manage, and verify registered students.

---

## ⚙️ Features
- Student registration for exams   
- Option to select subjects or courses  
- Simple and responsive UI  

---

## 🏗️ Tech Stack
**Frontend:** HTML, CSS, JavaScript 
**Backend:** Node.js, Express.js
**Database:** MySQL
